# 简谱演奏器

本软件仅供学习交流，下载后请24小时内删除。

这是可安装的 Android 应用项目。它接受文字简谱，支持保存多首自定义名称的歌曲，并在游戏悬浮窗中选曲；把 1–7 和高音 1 映射到屏幕上的八个位置，由用户启动后按节拍发送触摸手势。最低支持 Android 8.0（API 26）。图片简谱请先转换成下述文字格式，再粘贴到应用里。

## 手机上使用

1. 安装 `app/build/outputs/apk/debug/app-debug.apk`。
2. 启动页会显示学习交流提示。进入应用后，输入歌曲名称，粘贴简谱并设置 BPM，点击“保存为新曲”。以后可以载入、更新或删除已保存的曲目。同名歌曲不会重复保存。首次进入新版时会自动加入《我曾爱过一个人（内置）》，速度为 88 BPM；已有歌曲不会被覆盖。
3. 点击“开启无障碍点击服务”，在系统设置中开启“简谱演奏器点击服务”。对于部分 Android 13 及更新系统，如果服务显示为受限制，请先到“设置 → 应用 → 简谱演奏器 → 右上角菜单 → 允许受限设置”，再开启服务。
4. 返回应用，点击“显示悬浮控制条”。打开游戏的乐器界面，点击悬浮条的“调位置”，把八个圆点拖到琴键中心，再点击“保存位置”。每个圆点会按其实际屏幕位置保存。
5. 悬浮窗会显示当前曲名。按住曲名或左侧的“⠿”可以移动悬浮窗，位置会保存；控制条使用半透明背景。点击“选曲”可以切换已保存的歌曲；若正在演奏，会先停止当前歌曲。点击“试按”逐个检查 1–8 键，确认都落在琴键上，再点击“开始”。1.5 秒后开始演奏；随时可以点“停止”或“×”。

## 简谱格式

每个音符之间用空格隔开：`1 2 3 4 | 5 6 7 8`。`8` 或 `1'` 代表高音哆，`0` 是休止符，`[135]` 代表同时按下 1、3、5。默认一个音符占一拍；`3/2` 占半拍，`3*2` 占两拍，独立的 `-` 延长前一个事件一拍。竖线只用于排版。

当前只提供一个八键布局，切换游戏或屏幕方向后需重新校准。升级到 1.1 后，旧版的相对坐标不会自动沿用，须在游戏里重新调位置并保存。升级到 1.2 时，旧版已输入并保存过的曲谱会迁移为“旧版曲谱”。

## 图片简谱转换提示

主界面下滑可找到“如何把简谱图片转成可用文字”，并点击“复制 AI 转谱提示词”。把提示词连同简谱图片发给可识图的免费 AI，复制它输出的纯曲谱代码块，再粘贴进应用。请核对低音点、节奏和转调；当前八键布局不能完整表达这些记号。

## 构建

用 Android Studio 打开此目录，等待同步完成，再用 **Build → Build APK(s)** 导出可安装的调试 APK。命令行可运行 `gradlew.bat assembleDebug`。Android SDK 路径写在本机的 `local.properties` 中；换电脑后 Android Studio 会重新生成该文件。Gradle 依赖需要首次联网获取。

该项目使用系统无障碍手势，不请求 root，不读取游戏数据，也不提供隐藏自动化或规避游戏检测的机制。不同游戏对跨应用触摸的响应不同，需要在手机上实测。
